# 鲸鱼娘精灵图

- `sheet.png`:6 列 × 5 行、共 30 帧的透明精灵图,每格是正方形,包含两次出拳
- `thumb.png`:设置页用的缩略图(第 0 帧)
- `meta.json`:播放时间轴

## 时间轴

`idle` 是待机时循环播放的帧,`combo` 是一套敲屏动作。每项的格式是 `[帧号, 停留毫秒, 标记, 拳头x, 拳头y]`:

- `windup`:蓄力。镜头往后退一点
- `hit`:砸中。触发震屏、闪白、裂纹、声音和镜头冲击;拳头 x、y 是拳头在这一格里的位置(占宽高的比例),裂纹从这里裂开

想要打击感更强,主要调这几处:蓄力帧停久一点,出拳那几帧压到 30ms 左右,`hit` 帧停 100~140ms(打击停顿)。

## 换素材

换成同样排布的精灵图后,改 `cols`、`rows` 和时间轴即可。现在每格只有 229px,放大到半屏会发糊;如果能生成每格 512px 以上的版本,画面会清晰很多。
